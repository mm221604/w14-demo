# 期末範例網站｜毛孩商店街（展示版）

網址：https://maoxiaohai-demo.vercel.app （商店街首頁 `/入口頁.html`）

一組三個人、一條寵物商圈、三間風格不同的店。插畫全部是同一種手繪水彩風（AI 生成），每間店最上面都有一條橘色「毛孩商店街」商圈帶連回首頁。店名、人名、電話都是虛構的示範資料。

## 商店街首頁 `入口頁.html`（W16）
- 開場影片 `img/opening.mp4`（第一次進站自動播，可跳過、可重播）
- 可以點的插畫地圖：三間店有熱區、名牌、標記；車燈閃爍、路人走過等小動畫
- 三間店的營業中燈號（依台灣時間）
- 我要找哪一家：選寵物＋需求 → 推薦店家、地圖上把那間店圈出來
- 本週商圈活動、三張店卡、組員

## 毛小孩の家（根目錄，王小美）— 有資料庫
| 頁面 | 功能 |
|---|---|
| `index.html` | 滿版主圖、營業中燈號、美容前後拖拉滑桿、工具卡、評價輪播 |
| `booking.html` | **線上預約**：選日期與時段（被約走的變灰），存進 Neon；同一時段只能一筆 |
| `member.html` | 註冊／登入（Neon Auth）、**集點卡**、我的預約（可取消）、我的毛孩 |
| `calc.html`、`look.html`、`care.html` | 價格試算、危險食物、美容後照護 |
| `api/` | `pets.js`、`bookings.js`（只讀寫自己的資料）、`config.js`（只回傳公開的登入網址）、`_auth.js` |

## 汪汪行動美容車 `van/`（陳大明）
| 頁面 | 功能 |
|---|---|
| `index.html` | 方案卡（基礎洗澡、全套美容、SPA、老犬友善）、多毛孩優惠計算、車內設備熱點 |

## 喵喵美容室 `cat/`（林小華）

## 上線與資料庫
- 放在 Vercel，接上 Neon `maoxiaohai-db`（Auth 開、Connect 到專案）；資料庫密碼只在 Vercel 環境變數。
- Neon Settings → Better Auth → Domains 要有 `https://maoxiaohai-demo.vercel.app`，否則註冊會出現 Invalid origin。
- 真正做的時候三間店各在店長自己的 repo；範例為了放在一起才同一個網站。
