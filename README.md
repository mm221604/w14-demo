# 期末範例網站｜毛孩商店街（W14 示範）

W11 示範、W16 講評分標準時投影用。展示期末的兩層：

- **一個人的店**（`index.html` 等）：王小美把自己前半學期的作品做成店家網站，W11–W15 每個人做的就是這個，放在自己的 repo `W11`。
- **商圈首頁**（`入口頁.html`）：每組一條寵物商圈。W16 組員討論後由一人做、放在自己的 repo `W16`，只放連結，連到每個組員的 W11 網址；另有跨店的「我要找哪一家」（選寵物和需求 → 推薦哪一家、按鈕連過去）。
- **另外兩間店**（`van/` 汪汪行動美容車、`cat/` 喵喵美容室）：各有首頁＋一個功能頁，示範同一條商圈裡不同店型。真正做的時候各在店長自己的 repo `W11`；三間店各有自己的 `style.css`、風格不同（毛小孩の家暖橘木頭感、行動美容車青綠路線車票、喵喵美容室紫粉圓角腳印），共同點只有最上面那條橘色的「毛孩商店街」商圈帶。

店名、人名、電話都是虛構的。

## 刻意示範的幾件事

- **每頁頂部導覽 ＋「← 回首頁」**：期末評分「頁面互通」。
- **首頁最下面的「這間店是怎麼做出來的」**：每樣東西來自哪一週，發表時照這張表講。
- **商圈首頁每間店都點得進去、每間店最上面都有「毛孩商店街」商圈帶連回來**：期末評分「商圈首頁與串連」。
- **沒有線上預約按鈕**：網頁存不了資料，做了就是第 7 週那個假的「預約成功」，所以直接寫電話和 LINE。
- **不連任何外部 CDN**：學校網路會擋 `cdn.tailwindcss.com`，連了就變純文字。
- **價格與價目表一致**：試算頁的基本價和首頁那張木牌一樣。

## 上線與會員功能（W14）

- 網址：https://maoxiaohai-demo.vercel.app （商店街首頁：`/入口頁.html`）。
- 放在 Vercel，接上 Neon 資料庫 `maoxiaohai-db`（Auth 開、Connect 到專案）。資料庫密碼只在 Vercel 環境變數，程式裡沒有。
- 毛小孩の家多一頁 `member.html`：Neon Auth 註冊／登入，`api/pets.js` 存「我的毛孩」，只讀寫自己的資料；`api/config.js` 只回傳公開的登入網址。
- Neon 的 Settings → Better Auth → Domains 要加 `https://maoxiaohai-demo.vercel.app`，否則註冊會出現 Invalid origin。
